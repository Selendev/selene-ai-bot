
# Selene AI Bot 🤖💋

A seductive Telegram AI bot powered by GPT-3.5 and text-to-speech.

## Features
- Flirty chatbot personality
- Voice messages
- Fully hosted on Render.com for free

## Setup
1. Fork this repo
2. Add your `TELEGRAM_BOT_TOKEN` and `OPENAI_API_KEY` in Render environment
3. Deploy using `render.yaml`
